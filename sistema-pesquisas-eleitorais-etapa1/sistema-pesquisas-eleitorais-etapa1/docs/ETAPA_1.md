# Etapa 1 — Estrutura Inicial

## Objetivo

Configurar o ambiente de desenvolvimento, preparar o repositório de controle de versão, organizar a estrutura inicial do projeto e criar protótipos funcionais das telas principais com navegação básica.

## Ambiente

- Linguagem: Java 17
- Interface: Swing
- Gerenciamento: Maven
- Controle de versão: Git/GitHub

## Estrutura

O projeto foi organizado em camadas/pacotes iniciais para permitir a evolução posterior:

- `apresentacao`: telas e interação com o usuário;
- `aplicacao`: serviços/controladores a serem desenvolvidos;
- `dominio`: classes do domínio, separadas por módulo;
- `persistencia`: camada reservada para armazenamento de dados;
- `infraestrutura`: recursos auxiliares do sistema.

## Protótipos

Foram preparados:

- Login;
- Menu principal;
- Administração;
- Pesquisas;
- Coleta e Amostra;
- Análise Estatística e Relatórios;
- Candidatos e Partidos.

## Limites desta etapa

Não foram implementadas regras de negócio, persistência de dados ou processamento estatístico. A finalidade é apresentar a estrutura inicial e a navegabilidade básica, conforme previsto para a Etapa 1.
